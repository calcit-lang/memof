# Upgrade to Calcit 0.14.5 and tighten type checks

升级到 Calcit 0.14.5，并将 CI 切换到原生严格质量门禁。

- 将 `deps.cirru` 与 `@calcit/procs` 升级到 `0.14.5`。
- 删除已归档且不再使用的 `calcit-test` 开发依赖，测试改用内置 `calcit.test`。
- 为 `memof1-call` / `memof1-call-by` 的缓存增加不透明的 typed adapter 和 `MemoEntry`，限制开放值只在适配边界流动。
- 增加 `clear-memof1-function!`，避免消费者直接修改不透明缓存结构。
- 保留 anchor 与旧 `memof1-as` 缓存中 5 个必要的开放状态槽位，并通过逐 definition baseline 阻止增长。
- 为默认 entry 声明 native target，启用 public API、examples、dynamic-method 与 quality 检查。
- 删除未使用的 demo `*states` 全动态定义，并迁移严格模式下的 Option 访问。

English summary: upgrade the toolchain to Calcit 0.14.5, narrow open memo-cache values behind typed adapters, and enforce the reviewed strict-quality budget in CI.
