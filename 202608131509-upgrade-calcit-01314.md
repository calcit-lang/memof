# Calcit 0.13.14 migration

- Canonicalized the Snapshot into `:entries.default` and quoted type schemas.
- Removed the deprecated `calcit-test` root dependency and migrated tests to built-in `calcit.test` definition-attached unit tests.
- Migrated legacy record access to Struct access and made `nth`, `first`, `last`, and map field reads explicitly handle `Option`.
- Replaced the function-local anchor trait attachment with top-level Struct, trait, and implementation definitions so dynamic method checks can specialize it.
- CI now checks canonical formatting, both strict preprocessing modes, and the attached unit test suite before native/JS behavior and docs checks.

The remaining `Dynamic` schemas protect memoization's polymorphic value/key boundary. They are tracked by Calcit analysis reports, while normal and dynamic-method preprocessing are both warning-free.
